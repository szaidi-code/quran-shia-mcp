Your First Study Session: How to Use #

Once you connect https://quran-shia-mcp.onrender.com/mcp in Claude, ChatGPT, Antigravity, or Cursor, you can immediately ask questions by Surah/Ayah reference, Arabic phrase, or theological topic. Every response is grounded in canonical Tanzil Simple v1.1 Arabic text and verified Shia scholarship.

1

Connect

Add https://quran-shia-mcp.onrender.com/mcp to your AI client with server name quran-shia. No API key or OAuth login is required.

2

Read Verbatim Arabic

Ask for any verse or range (e.g. "Show me Surah An-Nur 24:55"). The AI calls fetch_quran or fetch_translation and renders the full vocalized Arabic text at the top.

3

Compare Shia Tafseer

Ask "Give me the Tafseer of 5:55" to compare Tafseer al-Kauthar (Allama Sheikh Mohsin Ali Najafi) and Tafseer e Namoona (Ayatollah Makarem Shirazi).

4

Search Across 114 Surahs

Search by unvocalized Arabic (e.g. ليذهب عنكم الرجس اهل البيت), Urdu, or English topics via search_verses to discover related verses and footnotes.

Troubleshooting #

Common setup, connection, and grounding verification checks across AI clients.

Server naming & invocation

Use quran-shia as the server name and https://quran-shia-mcp.onrender.com/mcp as the hosted Streamable HTTP endpoint. No API key or OAuth login is required.

Ensuring Arabic text is always visible

Every tool response embeds grounding_rules instructing the model to display the verbatim Tanzil Simple v1.1 arabic text at the top of its response. You can also call fetch_quran directly.

Claude Web Connector sign-in prompt

Because this server is open and requires no OAuth login, if Claude Web shows "Couldn't determine how this server signs in", click Continue anyway and leave auth set to None.

Did it use retrieved sources?

Look for tool invocations such as fetch_quran, fetch_translation, fetch_tafseer, or search_verses. Ask the assistant to cite the exact verse_key and scholarly author.

Selecting a specific translation or Tafseer

Pass edition="jawadi", "balagh", or "namoona" to fetch_translation, or pass source="kauthar" or "namoona" to fetch_tafseer. Call list_editions() to inspect all IDs.

Render free-tier wake-up

If the hosted instance on Render has been idle, the very first request may take 15–30 seconds to wake the container. Once warm, all 6,236 verses are served from local SQLite in under 50ms.
