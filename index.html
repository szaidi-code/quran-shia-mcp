Scholarly Shia Quran & Tafseer

Stream verified translations and classical commentaries directly into Claude, ChatGPT, Cursor, and Antigravity. Powered by Balagh ul Quran (Allama Sheikh Mohsin Ali Najafi) and Tafseer e Namoona (Ayatollah Makarem Shirazi / Allama Safdar Hussain Najafi).

Hosted MCP URL https://quran-shia-mcp.onrender.com/mcp

Claude Desktop & Claude Web Connector

Connect this MCP server directly to Anthropic Claude to study verses with scholarly Tafseer commentary.

  1. For Claude Web Connectors (Pro/Team): Go to Settings > Connectors > Add custom connector. 
    Name: Shia Quran & Tafseer
URL:  https://quran-shia-mcp.onrender.com/mcp
    Note: Because this is a public server with no OAuth login required, if Claude displays "Couldn't determine how this server signs in", click Continue anyway and leave authentication set to No sign in / None.
  2. For Claude Desktop: Open your configuration file:
    • macOS: ~/Library/Application Support/Claude/claude_desktop_config.json
    • Linux: ~/.config/Claude/claude_desktop_config.json
    • Windows: %APPDATA%\Claude\claude_desktop_config.json 
    {
  "mcpServers": {
    "quran-shia": {
      "url": "https://quran-shia-mcp.onrender.com/mcp"
    }
  }
}
  3. Restart Claude Desktop. You will see the hammer tool icon appear with fetch_translation and fetch_tafseer!

ChatGPT Custom GPT / MCP Integration

Add this server as a Custom GPT Action or Developer MCP endpoint.

  1. Open ChatGPT > Explore GPTs > Create a GPT (or open your Developer MCP integrations).
  2. Under Actions, click Create new action.
  3. Set the Authentication to None (the server is open and rate-limited).
  4. For MCP-compatible ChatGPT builds, provide the MCP endpoint: 
    https://quran-shia-mcp.onrender.com/mcp

Antigravity & Cursor IDE Setup

Configure this MCP server inside Antigravity or Cursor in 10 seconds.

  1. Open your MCP configuration:
    • Antigravity: ~/.gemini/config/mcp_config.json
    • Cursor: Settings > Cursor Settings > Features > MCP > Add New MCP Server
  2. Paste the configuration block: 
    {
  "mcpServers": {
    "quran-shia": {
      "url": "https://quran-shia-mcp.onrender.com/mcp"
    }
  }
}

Available MCP Tools

These tools are automatically discovered by any connected AI assistant:

Tool Name Parameters Description
fetch_translation surah (int), ayah (int), edition ("all" | "balagh" | "namoona") Returns Arabic text with Balagh ul Quran (Sheikh Mohsin Ali Najafi) and Tafseer e Namoona (Safdar Najfi) translations and footnotes.
fetch_tafseer surah (int), ayah (int), source ("kauthar" | "namoona" | "all") Fetches detailed scholarly commentary from Al-Kauthar fi Tafsir al-Quran or Tafseer e Namoona.
search_verses query (str), edition ("all" | "balagh" | "namoona") Full-text search across Arabic text, Urdu translations, and commentary notes.
